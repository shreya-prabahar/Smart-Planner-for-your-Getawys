🌴 Smart Planner for Your Getaways

Smart Planner for Your Getaways is a web-based travel planning application mainly focused on exploring and planning trips across South India. It provides users with a convenient platform to explore destinations, create itineraries, manage travel expenses, and book restaurants, making the entire trip-planning process easier and more organized.

✨ Features
🗺️ Explore Destinations – Discover popular tourist destinations across South India.
📍 Location Details – View important places, cities, sightseeing spots, and attractions.
📅 Itinerary Planner – Create and organize personalized day-by-day travel plans.
💰 Expense Tracker – Record and monitor travel expenses and manage the trip budget.
🍽️ Restaurant Booking – Find and book restaurants during your trip.
🌴 South India Focused – Includes destinations from states such as Kerala, Tamil Nadu, Karnataka, Andhra Pradesh, and Telangana.
📱 User-Friendly Interface – Simple and easy-to-navigate design for travelers.
🛠️ Technologies Used
Frontend: HTML, CSS, JavaScript, React.js
Backend: Node.js
Database: MongoDB
Development Tools: VS Code, Git & GitHub
🌏 Destinations

The application currently focuses on popular South Indian destinations, including:

Kerala – Kochi, Alleppey, Wayanad, Munnar, Thekkady
Tamil Nadu – Chennai, Ooty, Kodaikanal, Madurai, Rameswaram
Karnataka – Bengaluru, Mysuru, Coorg, Hampi
Andhra Pradesh – Tirupati, Visakhapatnam, Vijayawada
Telangana – Hyderabad, Warangal

🎯 Project Objective

The main objective of this project is to develop an all-in-one smart travel planning platform that helps users explore South India, organize itineraries, track expenses, and manage restaurant bookings from a single application.
