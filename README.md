🥗 NutriGuard AI
Computer Vision Based Dietary Habit Analysis & Preventive Healthcare System
📌 Overview
NutriGuard AI is an AI-powered healthcare application that analyzes users' dietary habits using Computer Vision and Machine Learning. The system identifies food items from uploaded images, estimates their nutritional values, and provides personalized dietary recommendations to promote healthier lifestyle choices.

✨ Features
🍎 Food image recognition using Computer Vision
📊 Calorie and nutrient estimation
🤖 AI-powered chatbot for diet and health queries
📈 Dietary habit analysis
💡 Personalized nutrition recommendations
⚠️ Preventive healthcare alerts
📱 User-friendly web interface

🚀 How to Run
Clone the repository
git clone https://github.com/your-username/NutriGuard-AI.git
Navigate to the project
cd NutriGuard-AI
Install dependencies
npm install
or

pip install -r requirements.txt
Start the backend
python app.py
Start the frontend
npm start
